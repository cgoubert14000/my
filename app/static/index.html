Secours : coller une session copiée du navigateur

Dans Edge ou Chrome : F12 → onglet Réseau → clic droit sur la requête catalog → Copier → Copier en tant que cURL. Collez la commande ici : les cookies (y compris cf_clearance) et le User-Agent exact sont récupérés ensemble, ce que Cloudflare exige.
