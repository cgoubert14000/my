  VINTED SNIPER 1.3.8  —  demarrage en 30 secondes

  SI VOUS AVEZ VU :
  « Le navigateur n'a pas ouvert son port de debogage »
  -> C'est corrige en 1.3.8 : le bot reessaie avec un profil neuf,
     puis avec un autre navigateur (Chrome si Edge echoue), et
     affiche desormais la raison exacte (code de sortie + detail).

  DEBLOQUER EN 2 CLICS (gratuit)
  1. Bandeau rouge -> « Debloquer avec mon navigateur ».
  2. Une fenetre Edge s'ouvre sur Vinted. Cochez la case si
     Cloudflare la demande ; des que le catalogue s'affiche, la
     fenetre se ferme et les scans repartent.

  PLAN B, TOUJOURS DISPONIBLE (aucune automatisation)
  Reglages -> « Deblocage Cloudflare » -> « Secours : coller une
  session copiee du navigateur » :
  1. Ouvrez Vinted dans Edge, F12, onglet Reseau.
  2. Clic droit sur la requete « catalog » -> Copier -> Copier en
     tant que cURL.
  3. Collez dans le champ, cliquez « Importer cette session ».
  Les cookies (dont cf_clearance) ET le User-Agent exact sont
  recuperes ensemble : c'est ce que Cloudflare verifie.

  NOUVEAU EN 1.3.8
  - Lancement du navigateur : port explicite verifie en HTTP, chemin
    de profil absolu, code de sortie remonte, 4 tentatives max
    (profil persistant, profil systeme, autre navigateur).
  - Secours cURL : import d'une session copiee du navigateur.
  - Message d'erreur explicite quand tout echoue (quoi faire).

  NOUVEAU EN 1.3.7
  - Deblocage gratuit via le navigateur local (Edge/Chrome, CDP),
    sans aucune dependance supplementaire.
  - FlareSolverr / Byparr acceptes en priorite si vous en avez un.

  NOUVEAU EN 1.3.6
  - Plus de « Hors ligne » pendant un blocage : la pastille affiche
    « Verification Vinted ».
  - Flux SSE auto-repare (reconnexion + chien de garde 45 s).
  - Bandeau Cloudflare : cause (votre IP), age, bouton de test.
  - Bandeau « aucun webhook » : sans webhook, aucune alerte ne part.
  - Demarrage express : un mot-cle suffit pour creer un profil.

  NOUVEAU EN 1.3.5
  - Pause intelligente : 60 s, 2 min, 5 min apres une verification, au
    lieu de reessayer toutes les 20 s.
  - Le bouton "scan" est refuse pendant 25 s apres un blocage, avec le
    temps restant affiche : cliquer en boucle enfoncait le clou.
  - Message clair dans le dashboard (attendre / changer d'IP).

  LE TEST QUI TRANCHE EN 60 SECONDES
  1. Coupez le Wi-Fi.
  2. Activez le partage de connexion du telephone, connectez le PC.
  3. Relancez vinted-sniper.exe et lancez un scan.
     - Les annonces arrivent -> c'etait votre adresse IP. Attendez 1 h,
       ou gardez cette connexion.
     - Meme blocage -> ce n'est pas l'IP : proxy residentiel necessaire.

  RAPPEL
  - 1.3.5 : pause 60 s / 2 min / 5 min apres une verification, scan
    manuel refuse 25 s, message clair au lieu de « self-healing ».
  - 1.3.4 : le mot "datadome" ne fait plus passer une page valide pour
    un blocage (faux positif corrige), User-Agent figé par domaine.
  - 1.3.3 : cookies conserves sur HTTP 200, session renouvelee apres
    3 blocages seulement.
  - 1.3.2 : temps reel 1 tentative / 10 s, fiche article bornee a 3,5 s,
