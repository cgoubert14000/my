  VINTED SNIPER 1.3.7  —  demarrage en 30 secondes

  VOTRE JOURNAL DIT : page « challenge-platform »
  C'est une verification navigateur (Cloudflare) servie a la place du
  catalogue. Le bot ne peut pas executer ce JavaScript, MAIS votre
  navigateur le peut : la 1.3.7 s'en sert.

  NOUVEAU EN 1.3.7 - DEBLOQUER EN 2 CLICS, GRATUITEMENT
  1. Cliquez sur le bouton vert du bandeau rouge :
     « Debloquer avec mon navigateur ».
  2. Une fenetre Edge (ou Chrome) s'ouvre sur Vinted.
     - Si Cloudflare affiche une case a cocher, cochez-la.
     - Des que le catalogue s'affiche, la fenetre se ferme.
  3. Le journal affiche « Session importee depuis le navigateur
     (N cookies, clearance : oui) » et les scans repartent
     immediatement. Rien a installer, aucune dependance ajoutee.

  Options (facultatives), dans « Reglages rapides » :
  - FlareSolverr / Byparr deja lance en Docker ? Collez son adresse
    (http://127.0.0.1:8191) : le bot l'utilisera en priorite.
  - Navigateur installe ailleurs (portable, autre disque) ? Indiquez
    son chemin (challenge.browser_path).
  - « Fenetre invisible » : plus rapide, mais une verification
    interactive ne peut alors pas etre validee a la main.

  A SAVOIR
  - Un captcha interactif ne se contourne pas : si Cloudflare en
    demande un a chaque requete, il faut le faire, ou utiliser un
    proxy residentiel (payant). Les proxys publics gratuits sont
    deja bloques.
  - Le cookie cf_clearance est lie a votre IP ET au navigateur : le
    bot reutilise les deux ensemble, sinon Cloudflare le refuse.

  NOUVEAU EN 1.3.6
  - Plus de « Hors ligne » pendant un blocage : la pastille affiche
    « Verification Vinted ».
  - Flux SSE auto-repare (reconnexion + chien de garde 45 s).
  - Bandeau Cloudflare : cause (votre IP), age, bouton de test.
  - Bandeau « aucun webhook » : sans webhook, aucune alerte ne part.
  - Demarrage express : un mot-cle suffit pour creer un profil.

  NOUVEAU EN 1.3.5
  - Pause intelligente : 60 s, 2 min, 5 min apres une verification, au
    lieu de reessayer toutes les 20 s.
  - Le bouton "scan" est refuse pendant 25 s apres un blocage, avec le
    temps restant affiche : cliquer en boucle enfoncait le clou.
  - Message clair dans le dashboard (attendre / changer d'IP).

  LE TEST QUI TRANCHE EN 60 SECONDES
  1. Coupez le Wi-Fi.
  2. Activez le partage de connexion du telephone, connectez le PC.
  3. Relancez vinted-sniper.exe et lancez un scan.
     - Les annonces arrivent -> c'etait votre adresse IP. Attendez 1 h,
       ou gardez cette connexion.
     - Meme blocage -> ce n'est pas l'IP : proxy residentiel necessaire.

  RAPPEL
  - 1.3.5 : pause 60 s / 2 min / 5 min apres une verification, scan
    manuel refuse 25 s, message clair au lieu de « self-healing ».
  - 1.3.4 : le mot "datadome" ne fait plus passer une page valide pour
    un blocage (faux positif corrige), User-Agent figé par domaine.
  - 1.3.3 : cookies conserves sur HTTP 200, session renouvelee apres
    3 blocages seulement.
  - 1.3.2 : temps reel 1 tentative / 10 s, fiche article bornee a 3,5 s,
    journal pousse en direct, interface sans clignotement.
